# Roadmap

| Stage | Deliverable | Acceptance criterion |
| --- | --- | --- |
| Delivered · 2.6.0 | Review before opening a draft | Missing title, brand or selling price is named. An incomplete product can be saved. Zero survives capture and editing. |
| Delivered · 2.6.0 | Local catalog and editable markup | Edited card values survive a bulk price calculation. Products without a base price keep their selling price. |
| Delivered · 2.6.1 | Reproducible catalog demo | A browser check edits a product, reloads, applies markup and previews the selected destination using fictional data. |
| Next · One real seller journey | Validate an owned eBay listing through an Etsy draft | Compare title, photos, price, currency, description and brand with the source. Record a redacted walkthrough and the fields the seller had to complete. |
| Next · Currency and provenance | Store source currency and the origin of each field | A EUR listing retains EUR after a reload. A destination with a different currency requests an explicit decision. |
| Then · Marketplace coverage | Test each advertised destination and regional form independently | Publish a matrix with date, locale, account prerequisites and verified fields. Show unsupported paths in the UI. |
| Then · Permissions and recovery | Limit media access and handle storage failures | Denied image access leaves text drafts usable. A failed save displays a recoverable error. |
